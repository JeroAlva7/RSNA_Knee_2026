Proyecto para la competencia de Kaggle RSNA Knee Abnormality Detection.

- Exploración inicial realizada con inspect_data.py.

## Estructura

- src/: código del modelo y pipeline.
- notebooks/: notebooks utilizados en Kaggle.
- inspect_data.py: análisis inicial de los datos.
- requirements.txt: dependencias del proyecto.

Los datasets, imágenes DICOM, modelos y credenciales no se incluyen en el repositorio.
